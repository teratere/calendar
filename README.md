# 📅 calendar

A clean, responsive viewer calendar with hybrid Japanese holiday support.

月曜始まり、見やすい土日色分け、そしてオフラインでも動くハイブリッド祝日同期を備えたシンプルで洗練されたWebカレンダーです。

## 🌟 特徴 (Features)
- **月曜始まりレイアウト:** 週の始まりを月曜日に統一
- **土日・祝日のメリハリ色分け:** 土曜は青系、日曜・祝日は赤系で平日と直感的に区別
- **月末週までのスマート表示:** 翌月の不要な日付マスを最小限に抑えたすっきりグリッド
- **ハイブリッド祝日判定:**
  - 通信不要で一瞬で動く「祝日自動計算ロジック」
  - 内閣府データ準拠のオープン祝日APIとの非同期同期＆キャッシュ保存
- **ダークモード対応:** 右上のアイコンからワンタップで切り替え
- **マルチデバイス対応:** PC・スマートフォンのどちらでも快適に閲覧可能

## 🛠 開発について (About)
このプロジェクトは、**生成AI（Gemini）を活用したバイブコーディング（対話型プログラミング）**によって作成されたシングルファイルWebアプリケーションです。

- **企画・仕様設計・ディレクション:** teratere
- **AIアシスタント (コード生成):** Gemini 3 Flash
- **構成技術:** HTML5 / Tailwind CSS / Vanilla JavaScript
